# Generate social media images from briefs with Google Gemini and Gmail

### 1. Workflow Overview

This workflow automates the creation and delivery of AI-generated social media images based on user-submitted requests. Its primary purpose is to bridge the gap between simple, rough user briefs and high-quality image generation by using an AI "art director" step to expand and refine prompts before passing them to an image generation model. 

Target use cases include marketing teams, content creators, or automated systems that require rapid visual asset generation driven by structured user input.

The workflow logic is grouped into three main functional blocks:
- **1.1 Input Reception & Art Direction:** Collects user requirements via an interactive form and uses a Google Gemini language model to transform a rough brief into a detailed, professional image-generation prompt.
- **1.2 Image Generation & Error Handling:** Takes the refined prompt and requests an image from Google Gemini, featuring a dedicated error-handling branch that notifies the user if generation fails.
- **1.3 Logging & Delivery:** Appends successful generation logs to a Google Spreadsheet and delivers the final image as an email attachment via Gmail.

### 2. Block-by-Block Analysis

#### 2.1 Input Reception & Art Direction
This block handles the entry point of the workflow, capturing user specifications through a web form and enhancing the raw input into a detailed, context-rich prompt tailored for visual generation models.

- **Image Brief Form**
  - **Type and technical role:** `n8n-nodes-base.formTrigger` — Acts as the webhook-based trigger that displays an interactive submission form to end users.
  - **Configuration choices:** Configured with custom field labels, placeholders, and validation rules. It requests an email address, intended use case, detailed description, and a dropdown selection for visual style (*Photorealistic*, *Flat illustration*, *3D render*, *Watercolor*, *Minimalist*).
  - **Key expressions or variables:** None (this node initiates data flow).
  - **Input and output connections:** No inputs (trigger node); outputs to *Art-Direct the Prompt with Gemini*.
  - **Version-specific requirements:** Version 2.6.
  - **Edge cases or potential failure types:** Form submissions depend on network availability and user adherence to required fields.

- **Google Gemini Chat Model**
  - **Type and technical role:** `@n8n/n8n-nodes-langchain.lmChatGoogleGemini` — Provides the underlying language model infrastructure for the prompt-engineering chain.
  - **Configuration choices:** Uses model `models/gemini-3.1-flash-lite` with a temperature setting of `0.7` for creative balance.
  - **Key expressions or variables:** None.
  - **Input and output connections:** Connects to the language model parameter input of *Art-Direct the Prompt with Gemini*.
  - **Version-specific requirements:** Version 1.1. Requires valid Google Gemini (PaLM) API credentials.
  - **Edge cases or potential failure types:** API quota limits, invalid credentials, or service timeouts.

- **Art-Direct the Prompt with Gemini**
  - **Type and technical role:** `@n8n/n8n-nodes-langchain.chainLlm` — Executes an LLM chain to process the form input using the connected chat model.
  - **Configuration choices:** Defined prompt structure instructing the model to act as an art director, synthesizing composition, lighting, color palette, lens/mood, and the user's chosen style into a 40–70 word prompt.
  - **Key expressions or variables:** `{{ $json.Style }}`, `{{ $json['What is the image for'] }}`, `{{ $json['Describe it'] }}`.
  - **Input and output connections:** Receives input data from *Image Brief Form* and language model configurations from *Google Gemini Chat Model*; outputs to *Generate Image with Gemini*.
  - **Version-specific requirements:** Version 1.9.
  - **Edge cases or potential failure types:** Expression evaluation failures if form fields are missing or renamed.

---

#### 2.2 Image Generation & Error Handling
This block converts the refined textual prompt into binary image data and manages potential downstream execution failures gracefully.

- **Generate Image with Gemini**
  - **Type and technical role:** `@n8n/n8n-nodes-langchain.googleGemini` — Generates visual media from textual prompts.
  - **Configuration choices:** Uses resource type `image` with model ID `models/gemini-3.1-flash-image-preview`. Configured to output the resulting file to a binary property named `image`. Error handling is set to `continueErrorOutput` to catch generation failures.
  - **Key expressions or variables:** `={{ $json.text }}` (pulls the art-directed prompt generated by the previous chain node).
  - **Input and output connections:** Receives input from *Art-Direct the Prompt with Gemini*. Splits into two output paths: Main success output connects to *Log Image*; error output connects to *Email Generation Failure*.
  - **Version-specific requirements:** Version 1.2. Requires Google Gemini (PaLM) API credentials.
  - **Edge cases or potential failure types:** Content moderation blocks, service outages, or unparseable prompt outputs resulting in execution faults directed to the error branch.

- **Email Generation Failure**
  - **Type and technical role:** `n8n-nodes-base.gmail` — Sends a notification email to the requester when image generation fails.
  - **Configuration choices:** Plain text email type with a pre-defined failure subject and explanatory message body.
  - **Key expressions or variables:** `={{ $(\"Image Brief Form\").item.json[\"Your email\"] }}` (retrieves the requester's email address from the trigger node).
  - **Input and output connections:** Receives input from the error output of *Generate Image with Gemini*.
  - **Version-specific requirements:** Version 2.2. Requires Gmail OAuth2 credentials.
  - **Edge cases or potential failure types:** Invalid recipient email or expired Gmail OAuth tokens.

---

#### 2.3 Logging & Delivery
This block records successful generation runs in a structured database and delivers the final asset to the end user.

- **Log Image**
  - **Type and technical role:** `n8n-nodes-base.googleSheets` — Appends a new row to a designated Google Sheet.
  - **Configuration choices:** Operation set to `append`. Target document and sheet/tab (named "Images") must be configured by the user.
  - **Key expressions or variables:** Inherits upstream data containing the prompt details.
  - **Input and output connections:** Receives success output from *Generate Image with Gemini*; outputs to *Email the Image*.
  - **Version-specific requirements:** Version 4.7. Requires Google Sheets OAuth2 credentials.
  - **Edge cases or potential failure types:** Spreadsheet permission errors, missing columns, or renamed sheets.

- **Email the Image**
  - **Type and technical role:** `n8n-nodes-base.gmail` — Sends the finalized generated image as an email attachment.
  - **Configuration choices:** Configured to send plain text emails with attachments enabled, pulling binary data from the `image` property.
  - **Key expressions or variables:** 
    - Recipient: `={{ $(\"Image Brief Form\").item.json[\"Your email\"] }}`
    - Subject: `={{ \"Your image is ready - \" + $(\"Image Brief Form\").item.json[\"What is the image for\"] }}`
    - Message body: `={{ \"Here is your generated image, attached.\\n\\nPrompt used:\\n\" + $(\"Art-Direct the Prompt with Gemini\").item.json.text }}`
    - Attachment property: `image`
  - **Input and output connections:** Receives input from *Log Image*.
  - **Version-specific requirements:** Version 2.2. Requires Gmail OAuth2 credentials.
  - **Edge cases or potential failure types:** Attachment size limits enforced by Gmail, or missing binary properties due to upstream data loss.

### 4. Reproducing the Workflow from Scratch

1. **Create the Trigger Node:** Add an **Image Brief Form** (`n8n-nodes-base.formTrigger`) node. Set the form title to `AI image from a brief` and configure form fields:
   - Email field (Type: Email, Required: true)
   - Image purpose field (Type: Text/String, Label: `What is the image for`, Required: true)
   - Description field (Type: Textarea, Label: `Describe it`, Required: true)
   - Style dropdown field (Type: Dropdown, Label: `Style`, Options: `Photorealistic`, `Flat illustration`, `3D render`, `Watercolor`, `Minimalist`, Required: true)
   - Set form submission message to: `Thanks! Your image is being generated and will arrive by email shortly.`

2. **Add the LLM Chat Model:** Add a **Google Gemini Chat Model** (`@n8n/n8n-nodes-langchain.lmChatGoogleGemini`) node. Select model `models/gemini-3.1-flash-lite`, set temperature to `0.7`, and configure your Google Gemini (PaLM) API credentials.

3. **Add the LLM Chain Node:** Add an **Art-Direct the Prompt with Gemini** (`@n8n/n8n-nodes-langchain.chainLlm`) node. Connect the chat model node to its language model input. Set prompt type to define, and use the following prompt text:
   `You are an art director. Turn the rough brief into a single vivid image-generation prompt of 40-70 words. Add concrete detail on composition, lighting, colour palette, lens/mood and the "{{ $json.Style }}" style. Describe only what should be visible. Do not include any text or words in the image. Output only the prompt, nothing else.`
   `Purpose: {{ $json['What is the image for'] }}`
   `Brief: {{ $json['Describe it'] }}`
   Connect the output of **Image Brief Form** to this node.

4. **Add the Image Generation Node:** Add a **Generate Image with Gemini** (`@n8n/n8n-nodes-langchain.googleGemini`) node. Set resource to `image`, model ID to `models/gemini-3.1-flash-image-preview`, and binary property output to `image`. Set error handling to `Continue On Fail` (`continueErrorOutput`). Use expression `={{ $json.text }}` for the prompt parameter. Connect the output of the LLM chain node to this node.

5. **Add the Failure Notification Node:** Add a **Email Generation Failure** (`n8n-nodes-base.gmail`) node. Configure Gmail OAuth2 credentials. Set recipient to `={{ $("Image Brief Form").item.json["Your email"] }}`, subject to `We could not generate your image`, and message to `Sorry - the image could not be generated this time. Please try again, or simplify the description.` Connect the error output of **Generate Image with Gemini** to this node.

6. **Add the Logging Node:** Add a **Log Image** (`n8n-nodes-base.googleSheets`) node. Configure Google Sheets OAuth2 credentials, select your target spreadsheet, and select the sheet/tab named `Images`. Set operation to `append`. Connect the success output of **Generate Image with Gemini** to this node.

7. **Add the Delivery Node:** Add an **Email the Image** (`n8n-nodes-base.gmail`) node. Configure Gmail OAuth2 credentials. 
   - Set recipient to `={{ $("Image Brief Form").item.json["Your email"] }}`
   - Set subject to `={{ "Your image is ready - " + $("Image Brief Form").item.json["What is the image for"] }}`
   - Set message body to `={{ "Here is your generated image, attached.\n\nPrompt used:\n" + $("Art-Direct the Prompt with Gemini").item.json.text }}`
   - Under options, add an attachment pointing to binary property `image`.
   Connect the output of **Log Image** to this node.
