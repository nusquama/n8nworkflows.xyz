# Create LinkedIn posts and WordPress blogs with OpenAI and Google Sheets

### 1. Workflow Overview

This workflow functions as an AI Content Studio designed to automate the creation, previewing, and one-click publishing of LinkedIn posts and WordPress blog articles. It provides a user-facing submission interface, utilizes OpenAI models to generate text and image assets concurrently, logs draft data to cloud storage, presents an interactive preview page, and handles secure post-approval publishing to LinkedIn or WordPress.

The execution logic is divided into four primary blocks:
- **1.1 Input Reception & Configuration:** Captures content briefs via an n8n form trigger and sets foundational variables, identification parameters, and environment settings.
- **1.2 AI Content & Asset Generation:** Interacts with OpenAI (`gpt-4o-mini`) to generate structured text and a visual prompt, then creates a thumbnail graphic using `gpt-image-1`, converting and storing the binary file.
- **1.3 Data Persistence & Preview Generation:** Logs draft metadata to Google Sheets, uploads the thumbnail image to Google Drive, constructs an HTML preview payload, and renders it for the user.
- **1.4 One-Click Publishing Pipeline:** Listens for publication webhooks, verifies content status, downloads associated assets from Google Drive, branches logic based on the target platform (LinkedIn API or WordPress REST API), and updates the processing status.

#### Block 1.1: Input Reception & Configuration
- **Overview:** Receives raw content criteria from an interactive web form and initializes workflow configurations, unique identifiers, and destination parameters.
- **Nodes Involved:** `Content Request Form`, `⚙️ Workflow Configuration`

##### Node Details:
- **Content Request Form**
  - *Type & Technical Role:* `n8n-nodes-base.formTrigger` — Serves as the public-facing entry point, capturing parameters such as content format, topic categories, source preferences, tone, and thumbnail notes.
  - *Configuration Choices:* Configured with dropdowns, radio buttons, and textareas for inputs. Requires mandatory parameters for format, categories, topic source, and tone.
  - *Key Expressions or Variables:* None (generates input data structure).
  - *Input/Output Connections:* Inputs: None (Trigger). Outputs: Connects to `⚙️ Workflow Configuration`.
  - *Version-specific Requirements:* Type Version 2.2.
  - *Edge Cases / Potential Failures:* Form abandonment, missing required fields.

- **⚙️ Workflow Configuration**
  - *Type & Technical Role:* `n8n-nodes-base.set` — Assigns static and dynamic variables across the execution lifecycle.
  - *Configuration Choices:* Defines `imageSize` (1536x1024), `brandStyleNotes`, `publishWebhookUrl`, `google_spreadsheet_id`, `google_sheet_name`, and `drive_parent_folder_id`.
  - *Key expressions or variables:* 
    ```javascript
    {{ $execution.id }}-{{ Math.random().toString(36).substring(2, 10) }}
    ```
  - *Input/Output Connections:* Inputs: `Content Request Form`. Outputs: `Write the Content`.
  - *Version-specific Requirements:* Type Version 3.4.
  - *Edge Cases / Potential Failures:* Blank ID variables or unconfigured spreadsheet/folder IDs will cause subsequent Google API nodes to fail.

#### Block 1.2: AI Content & Asset Generation
- **Overview:** Sends the parsed request to OpenAI for structured text writing and generates a matching thumbnail graphic based on instructions or context.
- **Nodes Involved:** `Write the Content`, `Create Thumbnail Image`, `Convert Thumbnail to Base64`

##### Node Details:
- **Write the Content**
  - *Type & Technical Role:* `@n8n/n8n-nodes-langchain.openAi` — Generates formatted post content, titles, metadata, and an image prompt using `gpt-4o-mini`.
  - *Configuration Choices:* Enforces strict JSON output containing `chosenTopic`, `title`, `bodyHtml`, `bodyPlain`, `hashtags`, and `thumbnailPrompt`.
  - *Key expressions or variables:* Evaluates user inputs from the form trigger and configuration nodes using template strings (e.g., `{{ $json['Content format'] }}`).
  - *Input/Output Connections:* Inputs: `⚙️ Workflow Configuration`. Outputs: `Create Thumbnail Image`.
  - *Version-specific Requirements:* Type Version 1.8.
  - *Edge Cases / Potential Failures:* Malformed JSON responses from the LLM, API rate limits, or insufficient OpenAI credential permissions.

- **Create Thumbnail Image**
  - *Type & Technical Role:* `@n8n/n8n-nodes-langchain.openAi` — Generates a binary image asset using `gpt-image-1`.
  - *Configuration Choices:* Resource set to `image`, utilizing the prompt generated by the preceding text node and size properties from the configuration node.
  - *Key expressions or variables:* 
    ```javascript
    {{ $json.message.content.thumbnailPrompt }}
    {{ $('⚙️ Workflow Configuration').item.json.imageSize }}
    ```
  - *Input/Output Connections:* Inputs: `Write the Content`. Outputs: `Convert Thumbnail to Base64`.
  - *Version-specific Requirements:* Type Version 1.8.
  - *Edge Cases / Potential Failures:* Generation timeouts or content policy blocks.

- **Convert Thumbnail to Base64**
  - *Type & Technical Role:* `n8n-nodes-base.extractFromFile` — Converts binary image data into a Base64 string format suitable for embedding within HTML output.
  - *Configuration Choices:* Operation set to `binaryToPropery`, outputting to `imageBase64` while keeping the source binary intact.
  - *Key expressions or variables:* None.
  - *Input/Output Connections:* Inputs: `Create Thumbnail Image`. Outputs: `Upload Thumbnail to Drive`.
  - *Version-specific Requirements:* Type Version 1.1.
  - *Edge Cases / Potential Failures:* Missing binary stream from the image generation node.

#### Block 1.3: Data Persistence & Preview Generation
- **Overview:** Saves generated media assets to Google Drive, logs draft metadata to Google Sheets, compiles an HTML preview layout, and presents it to the user.
- **Nodes Involved:** `Upload Thumbnail to Drive`, `Save Draft to Google Sheets`, `Build Preview Page`, `Show Preview to User`

##### Node Details:
- **Upload Thumbnail to Drive**
  - *Type & Technical Role:* `n8n-nodes-base.googleDrive` — Uploads the generated thumbnail to a designated Google Drive folder.
  - *Configuration Choices:* File naming dynamically concatenates content IDs; targets the folder ID defined in workflow settings.
  - *Key expressions or variables:* 
    ```javascript
    {{ 'thumbnail-' + $('⚙️ Workflow Configuration').item.json.contentId + '.png' }}
    {{ $('⚙️ Workflow Configuration').item.json.drive_parent_folder_id }}
    ```
  - *Input/Output Connections:* Inputs: `Convert Thumbnail to Base64`. Outputs: `Save Draft to Google Sheets`.
  - *Version-specific Requirements:* Type Version 3.

- **Save Draft to Google Sheets**
  - *Type & Technical Role:* `n8n-nodes-base.googleSheets` — Appends draft metadata and status tracking values to a Google Sheet.
  - *Configuration Choices:* Maps values to columns: `contentId`, `format`, `title`, `bodyPlain`, `bodyHtml`, `hashtags`, `driveFileId`, `status` (hardcoded to `READY`), and `createdAt`.
  - *Key expressions or variables:* References data from `Write the Content`, `Content Request Form`, and Google Drive upload metadata (`$json.id`).
  - *Input/Output Connections:* Inputs: `Upload Thumbnail to Drive`. Outputs: `Build Preview Page`.
  - *Version-specific Requirements:* Type Version 4.5.

- **Build Preview Page**
  - *Type & Technical Role:* `n8n-nodes-base.set` — Assembles an inline HTML layout containing the embedded Base64 image, text elements, and a dynamic publication trigger link.
  - *Configuration Choices:* Assigns an HTML string to the `html` field, conditional upon the content format for styling and button labeling.
  - *Key expressions or variables:* Injects the Base64 image, generated text blocks, and the publication webhook URL appended with the unique `contentId`.
  - *Input/Output Connections:* Inputs: `Save Draft to Google Sheets`. Outputs: `Show Preview to User`.
  - *Version-specific Requirements:* Type Version 3.4.

- **Show Preview to User**
  - *Type & Technical Role:* `n8n-nodes-base.form` — Displays the completion/preview page to the submitter.
  - *Configuration Choices:* Operation set to `completion`, responding with the custom HTML string generated previously.
  - *Key expressions or variables:* 
    ```javascript
    {{ $json.html }}
    ```
  - *Input/Output Connections:* Inputs: `Build Preview Page`. Outputs: None (Terminal node for generation phase).
  - *Version-specific Requirements:* Type Version 1.

#### Block 1.4: One-Click Publishing Pipeline
- **Overview:** Receives webhook requests triggered by the preview page, validates the record state, downloads associated assets, posts to the correct destination platform (LinkedIn or WordPress), and marks the draft as processed.
- **Nodes Involved:** `Publish Button Clicked`, `⚙️ Publish Configuration`, `Find Draft by ID`, `Already Processed or Not Found?`, `Respond Already Processed`, `Download Thumbnail from Drive`, `Route by Format`, `Post to LinkedIn`, `Upload Thumbnail to WordPress`, `Create WordPress Draft`, `Mark Draft as Processed`, `Respond Publish Success`

##### Node Details:
- **Publish Button Clicked**
  - *Type & Technical Role:* `n8n-nodes-base.webhook` — Acts as the entry point when a user clicks the publish action button in the preview interface.
  - *Configuration Choices:* Path set to `content-studio-publish`, using response mode `responseNode`.
  - *Input/Output Connections:* Inputs: None (Webhook Trigger). Outputs: `⚙️ Publish Configuration`.
  - *Version-specific Requirements:* Type Version 2.

- **⚙️ Publish Configuration**
  - *Type & Technical Role:* `n8n-nodes-base.set` — Establishes WordPress integration parameters and spreadsheet tracking properties for the publishing route.
  - *Configuration Choices:* Defines `wordpressSiteUrl`, `google_spreadsheet_id`, and `google_sheet_name`.
  - *Input/Output Connections:* Inputs: `Publish Button Clicked`. Outputs: `Find Draft by ID`.
  - *Version-specific Requirements:* Type Version 3.4.

- **Find Draft by ID**
  - *Type & Technical Role:* `n8n-nodes-base.googleSheets` — Queries the tracking Google Sheet for a row matching the incoming publication `contentId`.
  - *Configuration Choices:* Operation set to lookup row using `contentId` filtered against the webhook query parameter (`$json.query.id`).
  - *Key expressions or variables:* 
    ```javascript
    {{ $json.query.id }}
    ```
  - *Input/Output Connections:* Inputs: `⚙️ Publish Configuration`. Outputs: `Already Processed or Not Found?`.
  - *Version-specific Requirements:* Type Version 4.5.

- **Already Processed or Not Found?**
  - *Type & Technical Role:* `n8n-nodes-base.if` — Evaluates whether the retrieved draft status is valid for publishing.
  - *Configuration Choices:* Checks if the status field `notEquals` to `READY`.
  - *Key expressions or variables:* 
    ```javascript
    {{ $json.status }}
    ```
  - *Input/Output Connections:* Inputs: `Find Draft by ID`. Outputs: True branch to `Respond Already Processed`, False branch to `Download Thumbnail from Drive`.
  - *Version-specific Requirements:* Type Version 2.

- **Respond Already Processed**
  - *Type & Technical Role:* `n8n-nodes-base.respondToWebhook` — Returns an HTML error response indicating the post has already been processed or is invalid.
  - *Configuration Choices:* HTML text response with a `text/html; charset=utf-8` header.
  - *Input/Output Connections:* Inputs: `Already Processed or Not Found?`. Outputs: None (Terminal node).
  - *Version-specific Requirements:* Type Version 1.1.

- **Download Thumbnail from Drive**
  - *Type & Technical Role:* `n8n-nodes-base.googleDrive` — Downloads the binary thumbnail asset associated with the draft's `driveFileId`.
  - *Configuration Choices:* Operation set to `download`, using the Google Drive file ID from the Sheet lookup.
  - *Key expressions or variables:* 
    ```javascript
    {{ $json.driveFileId }}
    ```
  - *Input/Output Connections:* Inputs: `Already Processed or Not Found?`. Outputs: `Route by Format`.
  - *Version-specific Requirements:* Type Version 3.

- **Route by Format**
  - *Type & Technical Role:* `n8n-nodes-base.switch` — Directs workflow execution based on the chosen output format.
  - *Configuration Choices:* Evaluates draft format as either `LinkedIn post` or `WordPress blog post`.
  - *Key expressions or variables:* 
    ```javascript
    {{ $('Find Draft by ID').item.json.format }}
    ```
  - *Input/Output Connections:* Inputs: `Download Thumbnail from Drive`. Outputs: Output 0 to `Post to LinkedIn`, Output 1 to `Upload Thumbnail to WordPress`.
  - *Version-specific Requirements:* Type Version 3.

- **Post to LinkedIn**
  - *Type & Technical Role:* `n8n-nodes-base.linkedIn` — Publishes text and attached image media directly to LinkedIn.
  - *Configuration Choices:* Sets share media category to `IMAGE`, combining plain text copy and hashtags.
  - *Key expressions or variables:* 
    ```javascript
    {{ $('Find Draft by ID').item.json.bodyPlain }}
    {{ $('Find Draft by ID').item.json.hashtags }}
    ```
  - *Input/Output Connections:* Inputs: `Route by Format`. Outputs: `Mark Draft as Processed`.
  - *Version-specific Requirements:* Type Version 1.

- **Upload Thumbnail to WordPress**
  - *Type & Technical Role:* `n8n-nodes-base.httpRequest` — Uploads the binary thumbnail image to the WordPress REST API media endpoint.
  - *Configuration Choices:* POST request to `/wp-json/wp/v2/media` using multipart/form-data with binary input data and custom filename headers.
  - *Key expressions or variables:* 
    ```javascript
    {{ $('⚙️ Publish Configuration').item.json.wordpressSiteUrl }}
    {{ $('Find Draft by ID').item.json.contentId }}
    ```
  - *Input/Output Connections:* Inputs: `Route by Format`. Outputs: `Create WordPress Draft`.
  - *Version-specific Requirements:* Type Version 4.2.

- **Create WordPress Draft**
  - *Type & Technical Role:* `n8n-nodes-base.httpRequest` — Creates a new post draft within WordPress using the uploaded media ID as the featured image.
  - *Configuration Choices:* POST request to `/wp-json/wp/v2/posts` with JSON body payloads specifying title, HTML body content, draft status, and `featured_media`.
  - *Key expressions or variables:* 
    ```javascript
    {{ JSON.stringify({ title: $('Find Draft by ID').item.json.title, content: $('Find Draft by ID').item.json.bodyHtml, status: 'draft', featured_media: $json.id }) }}
    ```
  - *Input/Output Connections:* Inputs: `Upload Thumbnail to WordPress`. Outputs: `Mark Draft as Processed`.
  - *Version-specific Requirements:* Type Version 4.2.

- **Mark Draft as Processed**
  - *Type & Technical Role:* `n8n-nodes-base.googleSheets` — Updates the tracking sheet status to `PROCESSED` using `contentId` as the match key.
  - *Configuration Choices:* Operation set to `appendOrUpdate` matching on `contentId`.
  - *Key expressions or variables:* 
    ```javascript
    {{ $('Publish Button Clicked').item.json.query.id }}
    ```
  - *Input/Output Connections:* Inputs: `Post to LinkedIn`, `Create WordPress Draft`. Outputs: `Respond Publish Success`.
  - *Version-specific Requirements:* Type Version 4.5.

- **Respond Publish Success**
  - *Type & Technical Role:* `n8n-nodes-base.respondToWebhook` — Returns a final confirmation HTML response to the browser session indicating successful publication or draft creation.
  - *Configuration Choices:* HTML content response with a `text/html; charset=utf-8` header, adapting messages based on the output format.
  - *Key expressions or variables:* Evaluates the format type to render platform-specific messaging.
  - *Input/Output Connections:* Inputs: `Mark Draft as Processed`. Outputs: None (Terminal node).
  - *Version-specific Requirements:* Type Version 1.1.

### 4. Reproducing the Workflow from Scratch

1. **Create Form Trigger Node:**
   - Create a `Form Trigger` node named `Content Request Form`.
   - Configure input fields: `Content format` (dropdown: LinkedIn post, WordPress blog post), `Topic categories` (multiselect dropdown), `Topic source` (radio), `Topic description` (textarea), `Tone` (dropdown), `Thumbnail source` (radio), and `Thumbnail instructions` (textarea).

2. **Add Workflow Configuration Node:**
   - Create a `Set` node named `⚙️ Workflow Configuration`.
   - Add string assignments: `imageSize` (`1536x1024`), `brandStyleNotes` (`none`), `publishWebhookUrl` (set to your production webhook URL), `contentId` (`={{ $execution.id }}-{{ Math.random().toString(36).substring(2, 10) }}`), `google_spreadsheet_id`, `google_sheet_name` (`posts`), and `drive_parent_folder_id`.
   - Connect `Content Request Form` to `⚙️ Workflow Configuration`.

3. **Add Text Generation Node (OpenAI):**
   - Create an OpenAI node (`Write the Content`) using model `gpt-4o-mini`.
   - Set messages to request strict JSON output containing keys: `chosenTopic`, `title`, `bodyHtml`, `bodyPlain`, `hashtags`, and `thumbnailPrompt`.
   - Add OpenAI API credentials.
   - Connect `⚙️ Workflow Configuration` to `Write the Content`.

4. **Add Image Generation Node (OpenAI):**
   - Create an OpenAI node (`Create Thumbnail Image`) set to resource `image`, model `gpt-image-1`.
   - Set prompt expression to `={{ $json.message.content.thumbnailPrompt }}` and size to `={{ $('⚙️ Workflow Configuration').item.json.imageSize }}`.
   - Connect `Write the Content` to `Create Thumbnail Image`.

5. **Convert Binary to Base64:**
   - Create an `Extract from File` node (`Convert Thumbnail to Base64`) with operation `binaryToPropery`, setting the destination key to `imageBase64`.
   - Connect `Create Thumbnail Image` to `Convert Thumbnail to Base64`.

6. **Upload Thumbnail to Google Drive:**
   - Create a `Google Drive` node (`Upload Thumbnail to Drive`).
   - Set operation to upload, file name to `={{ 'thumbnail-' + $('⚙️ Workflow Configuration').item.json.contentId + '.png' }}`, and folder ID to `={{ $('⚙️ Workflow Configuration').item.json.drive_parent_folder_id }}`.
   - Add Google Drive OAuth2 credentials.
   - Connect `Convert Thumbnail to Base64` to `Upload Thumbnail to Drive`.

7. **Save Draft to Google Sheets:**
   - Create a `Google Sheets` node (`Save Draft to Google Sheets`).
   - Set operation to append, document ID and sheet name from configuration.
   - Map columns: `contentId`, `format`, `title`, `bodyPlain`, `bodyHtml`, `hashtags`, `driveFileId` (`={{ $json.id }}`), `status` (`READY`), and `createdAt` (`={{ $json.createdTime }}`).
   - Add Google Sheets OAuth2 credentials.
   - Connect `Upload Thumbnail to Drive` to `Save Draft to Google Sheets`.

8. **Build and Display HTML Preview:**
   - Create a `Set` node (`Build Preview Page`) assigning an HTML template string to the `html` field, embedding the base64 image, generated text, and a publication link pointing to `publishWebhookUrl?id={{ contentId }}`.
   - Create a `Form` node (`Show Preview to User`) set to completion operation, responding with text `={{ $json.html }}`.
   - Connect `Save Draft to Google Sheets` -> `Build Preview Page` -> `Show Preview to User`.

9. **Create Publication Webhook & Verification Pipeline:**
   - Create a `Webhook` node (`Publish Button Clicked`) with path `content-studio-publish` and response mode `responseNode`.
   - Create a `Set` node (`⚙️ Publish Configuration`) assigning `wordpressSiteUrl`, `google_spreadsheet_id`, and `google_sheet_name`.
   - Create a `Google Sheets` node (`Find Draft by ID`) looking up rows where `contentId` equals `={{ $json.query.id }}`.
   - Create an `If` node (`Already Processed or Not Found?`) checking if `status` `notEquals` `READY`.
   - Create a `Respond to Webhook` node (`Respond Already Processed`) returning an HTML error message.
   - Connect `Publish Button Clicked` -> `⚙️ Publish Configuration` -> `Find Draft by ID` -> `Already Processed or Not Found?` -> `Respond Already Processed` (True branch).

10. **Add Publishing & Routing Logic:**
    - Create a `Google Drive` node (`Download Thumbnail from Drive`) set to download file ID `={{ $json.driveFileId }}`. Connect to the False branch of `Already Processed or Not Found?`.
    - Create a `Switch` node (`Route by Format`) routing based on format equal to `LinkedIn post` or `WordPress blog post`.
    - Create a `LinkedIn` node (`Post to LinkedIn`) set to share media category `IMAGE`, text combining `bodyPlain` and `hashtags`. Add LinkedIn OAuth2 credentials. Connect from Output 0 of `Route by Format`.
    - Create an `HTTP Request` node (`Upload Thumbnail to WordPress`) pointing to `{{ wordpressSiteUrl }}/wp-json/wp/v2/media`, method POST, sending binary data with header `Content-Disposition`. Add WordPress API credentials. Connect from Output 1 of `Route by Format`.
    - Create an `HTTP Request` node (`Create WordPress Draft`) pointing to `{{ wordpressSiteUrl }}/wp-json/wp/v2/posts`, method POST, sending a JSON body containing `title`, `content` (`bodyHtml`), `status` (`draft`), and `featured_media` (`{{ $json.id }}`). Add WordPress API credentials. Connect `Upload Thumbnail to WordPress` to `Create WordPress Draft`.

11. **Finalize Processing State & Success Response:**
    - Create a `Google Sheets` node (`Mark Draft as Processed`) set to appendOrUpdate matching on `contentId`, updating `status` to `PROCESSED`. Connect both `Post to LinkedIn` and `Create WordPress Draft` to this node.
    - Create a `Respond to Webhook` node (`Respond Publish Success`) returning a platform-specific HTML confirmation response.
    - Connect `Mark Draft as Processed` to `Respond Publish Success`.
